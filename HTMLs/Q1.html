Master Version Control

Git is the distributed version control system that tracks changes in your source code during software development.

Download PDF

Core Workflow

git init Initialize a new repository in the current folder.
git add . Stage all modified files for the next commit.
git commit -m "message" Commit staged changes with a descriptive message.
git status Show the status of changes as untracked, modified, or staged.
git push origin main Upload local repository content to a remote repository.

Pro Tips & Flags

  • Undo staging: Use git restore --staged <file> to unstage.
  • Amend commit: Use git commit --amend to fix the last commit message.
  • Discard changes: Use git checkout . to discard all local changes.
  • Log history: Use git log --oneline for a compact history view.

💡 Remember .gitignore

Always restart your repo by creating a .gitignore file to exclude node_modules or .env files.
