Horizontal Scroll Snap Demo

Scroll horizontally — the viewport will snap to each card.

Card — Introduction

This is a demo card. The container uses scroll-snap-type: x mandatory and each card uses scroll-snap-align: center.

Intro

Card — Features

Works with mouse wheel (with Shift), touch swipe, and trackpad. It’s responsive and keyboard-focusable.

Features

Card — Layout

Cards are flexible width. On larger screens multiple cards will appear partially, but snapping still centers one card at a time.

Layout

Card — Accessibility

Each card is keyboard-focusable. Buttons control smooth scrolling. Use Tab to focus a card then press Arrow keys to move focus if needed.

A11y

Card — Try Me

Use the Next and Prev buttons to move between cards programmatically (smooth scroll), or simply swipe/scroll to see native CSS snapping.
