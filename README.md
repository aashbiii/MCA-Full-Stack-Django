## Repository Overview

This repository contains the complete portfolio of **39 Practical Exercises** and the **Semester Capstone Project** developed for the Full Stack Development Laboratory.

The curriculum provides a progressive engineering pathway across modern web architecture:
1. **Frontend Tier (Q1 – Q17):** HTML5 semantic markup, CSS3 animations/flexbox/grid, JavaScript DOM/ES6, Bootstrap 5, Material Design, and client-side LocalStorage CRUD.
2. **Microservices & AJAX (Q18 – Q19):** Python Flask REST endpoints with asynchronous AJAX requests.
3. **Full-Stack Enterprise Tier (Q20 – Q39):** Django architecture, MTV (Model-Template-View) pattern, ORM database querying, authentication & RBAC, session management, pagination, and deployment.
4. **Capstone Web Application (Q40):** **Mentrix** — College Mentoring & Student Lifecycle System.

## Setup & Local Execution

### Frontend Exercises (Q1 – Q17)
Open any HTML file directly in a modern web browser:
```bash
# Example:
start "HTMLs/PG1 Horizontal Scroll.html"
```

### Flask AJAX Projects (Q18, Q19)
```bash
cd Q18
pip install flask
python app.py
```

### Django Projects (Q20 – Q38 & Mentrix)
```bash
# Navigate to desired project directory
cd mentorship

# Install dependencies
pip install django

# Run migrations & start local development server
python manage.py migrate
python manage.py runserver
```
